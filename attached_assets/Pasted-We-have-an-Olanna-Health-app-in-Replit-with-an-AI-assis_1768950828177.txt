A) Add “language mode” state

B) Language detection (simple + reliable)

Use these isiZulu markers (case-insensitive):
ngiy, ngicela, sawubona, unjani, ngikhathazekile, ubuhlungu, izinsuku, umjikelezo, ukuya esikhathini, igazi, namuhla, kusasa, ngabe, yebo, cha, kakhulu, kancane, phesheya, lapha

C) Build the system prompt with bilingual rules

When calling the AI endpoint, include a system/developer message that enforces language:

System prompt logic

	•	If languageMode is "en" → reply in English
	•	If "zu" → reply in isiZulu
	•	If "auto" → reply in detected language (from user message, or last language)
	•	The assistant must:
	•	Use warm, supportive tone.
	•	Keep medical advice cautious (not a doctor).
	•	Ask 1 short follow-up question if user message is ambiguous.
	•	Keep responses concise (3–8 short paragraphs/bullets).

Add this instruction exactly:
	•	“Reply ONLY in {replyLanguage}. Do not translate unless the user asks.”

D) Add a “language hint” UI (small)
