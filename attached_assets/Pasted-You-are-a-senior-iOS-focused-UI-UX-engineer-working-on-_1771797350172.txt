IMPORTANT
- Detect the current stack (React Native/Expo vs web). If it’s React Native/Expo, implement iOS-native patterns using the appropriate libraries.
- Do NOT rewrite the entire app. Upgrade UI patterns progressively and safely.
- Keep Olanna’s brand: soft, feminine, minimal — but use iOS system components/styles wherever possible.

------------------------------------------------------------
1) NAVIGATION: iOS-STYLE
------------------------------------------------------------
- Use iOS native-stack navigation where possible.
  If React Navigation: ensure @react-navigation/native-stack is used for iOS screens.

- Use native iOS back behavior and correct header spacing.
- Ensure tab bar follows iOS conventions: correct height, safe area padding, label + icon alignment.

------------------------------------------------------------
2) TYPOGRAPHY & LAYOUT: iOS SYSTEM RULES
------------------------------------------------------------
- Adopt Dynamic Type / scaling text so it respects user font settings.
- Use iOS system fonts (SF Pro) by default (do not hardcode custom fonts unless already used).
- Ensure consistent spacing/padding using iOS-friendly values (e.g., 16/20/24 grid).
- Respect safe areas everywhere (especially tab screens and modals).

------------------------------------------------------------
3) COMPONENTS: NATIVE iOS FEEL
------------------------------------------------------------
Update UI components to match iOS look & behavior:

A) Forms
- Use iOS-style form sections for inputs (Log Product screen).
- Use segmented controls, toggles, and date pickers that look native on iOS.

B) Lists
- Use iOS-style grouped lists (insets, separators, section headers).
- Use swipe actions on list rows (e.g., delete/edit product logs) with iOS swipe gestures.

C) Buttons
- Prefer iOS primary/secondary button styles (pill radius, subtle elevation).

D) Modals / Sheets
- Present secondary flows as iOS sheets (medium/large detents) where appropriate:

E) Materials / Blur
- Use iOS-style blur/material backgrounds sparingly (e.g., headers, cards, sheet backgrounds) using a blur library if RN/Expo.

------------------------------------------------------------
- Add light haptics on:

  - toggles

  - good contrast
