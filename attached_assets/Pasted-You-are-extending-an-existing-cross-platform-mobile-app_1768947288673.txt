You are extending an existing cross-platform mobile app called “Olanna Health” (women’s health hub for African—especially South African—women). The app already has: cycle tracking, PCOS & endometriosis modules, STI + Pap smear reminders, privacy-first storage, and a Lotus Flower cycle visualization (menstruation=closed bud, follicular=opening bud, ovulation=full bloom, luteal=petals closing/falling). 

TASK: Build a Stardust-level symptom & experience tracker (and better) with UI visuals that match the ENTIRE app aesthetic: “science meets softness”, minimalist, feminine, calm, premium; earthy neutrals + soft blushes + warm browns + muted gold accents; organic shapes; gentle gradients; subtle moonlight/cosmic glow; LOTUS motif consistent across screens; no harsh neon; excellent readability; accessibility-friendly contrast; light and dark mode.

1) Symptom Tracker System (Core Requirements)
- Create a structured symptom system with categories + items + icons + severity + notes.
- Reminder: user should be able to customize: pin favorites, hide symptoms, add custom symptoms, reorder categories.
- Input types: 
  a) quick-tap toggle (present/absent)
  b) severity slider 0–5
  c) optional free-text note
  d) optional tags (e.g., “work stress”, “heat”, “dehydration”, “load shedding”, “travel”, “poor sleep”)
- Add “Body Map Pain” feature: a simple front/back female silhouette or pelvic-focused map; user taps a region and logs pain type + severity + duration + triggers.
